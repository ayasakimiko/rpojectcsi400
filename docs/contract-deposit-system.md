# ระบบสัญญาเช่าและเงินมัดจำ

สรุปงานที่ทำกับระบบสัญญาเช่าทั้งหมด ช่วง 22–23 ต.ค. 2569 (branch `Backendtest`)
ครอบคลุมการทำสัญญา ยอดเงิน ต่อสัญญา ย้ายห้อง ย้ายออก ระงับบัญชี และการคืน/ริบเงินมัดจำ

---

## 0. กติกาที่ระบบใช้ตอนนี้

| เรื่อง | กติกา |
|---|---|
| ระยะสัญญา | 3, 6 หรือ 12 เดือน (ขั้นต่ำ 3 เดือน) |
| เงินมัดจำ | 2 เดือนของค่าห้อง บังคับทุกสัญญา (`DEPOSIT_MONTHS = 2`) |
| งวดแรก | ค่าห้องเดือนแรก + เงินมัดจำ จ่ายพร้อมกัน เดือนต่อไปจ่ายแค่ค่าห้อง |
| สัญญามีผล | เมื่อจ่ายงวดแรกครบ (ลูกค้าโอน หรือพนักงานเก็บเงินเอง) |
| ผ่อนผัน | 3 วันหลังครบรอบบิล |
| ต่อสัญญา | ต่อจากวันสิ้นสุดเดิม ครั้งละ 1/3/6/12 เดือน จ่ายรายเดือน ไม่เก็บมัดจำเพิ่ม |
| ย้ายห้อง / ต่อสัญญา / ย้ายออก | ต้องไม่มียอดค้างก่อน |
| แจ้งย้ายออก | เลือกวันย้ายได้ภายใน 60 วัน |
| รูปสัญญา | ตอนทำสัญญาอย่างน้อย 3 รูป · ตอนอนุมัติย้ายห้องอย่างน้อย 5 รูป |
| คืน/ริบมัดจำ | อยู่ครบสัญญา = **คืน** (หักค่าเสียหายได้) · ออกก่อนครบ = **ริบทั้งหมด** |
| ระงับบัญชี | นับเป็นการย้ายออก ณ วันที่ระงับ สัญญากลายเป็น "สัญญาเก่า" |

## 1. ลงทะเบียนผู้เช่าและทำสัญญา (หน้า `/register`)

- หน้าลงทะเบียนทำใหม่เป็น 4 ขั้น: ข้อมูลผู้เช่า / ห้องและสัญญา / รูปสัญญา / บัญชีเข้าใช้งาน แถบปุ่มด้านล่างติดจอ แสดงห้อง ระยะสัญญา และยอดเดือนแรก
- **กรอกเลขบัตรครบ 13 หลัก** ระบบดึงชื่อ นามสกุล เบอร์ อายุ ของผู้เช่าเดิมมาให้ (`GET /api/auth/register/lookup/:idcard` เฉพาะพนักงาน) ถ้าคนนั้นยังมีห้องอยู่จะขึ้นเตือนสีแดง
- ช่องเงินมัดจำแสดง "2 เดือน · ฿X" แก้เองไม่ได้ server คิดเองเป็นราคาห้อง × 2 และปฏิเสธค่าอื่น
- ระยะสัญญาเหลือ 3 / 6 / 12 เดือน server ปฏิเสธค่าอื่น
- รูปสัญญา: กล่องขนาดคงที่ ลากวางได้ ตรวจชนิดไฟล์จริง เก็บใน `ContractImage`
- กล่องสรุป: วันสิ้นสุดสัญญา และ ค่าห้อง + มัดจำ = ยอดเดือนแรก
- **ผู้เช่าเดิมที่ไม่มีห้องแล้ว** ลงทะเบียนด้วยเลขบัตรเดิมได้ ระบบใช้บัญชีเดิม อัปเดตข้อมูลและรหัสผ่าน ปลดระงับ แล้วสร้างสัญญาใหม่ สัญญาเก่ายังเก็บไว้
- เอาระบบ "ค่าประกัน" ที่เคยทดลองทำออกทั้งหมด และเปลี่ยนคำว่า "เงินประกัน" เป็น "เงินมัดจำ" ทุกหน้า

## 2. เงินมัดจำตอนชำระเงิน

- ยอดชำระเดือนแรกของลูกค้าแยกเป็น `เงินมัดจำ 2 เดือน (฿3,800 × 2)` + `ค่าเช่าห้อง`
- ส่งสลิปแล้ว มัดจำยังแสดงคู่กับค่าเช่าในสถานะ "รอตรวจสลิป" จนพนักงานอนุมัติ
- กันบันทึกมัดจำซ้ำ ทั้งตอนลูกค้าส่งสลิปและตอนพนักงานเก็บเงินสด
- ประวัติการเช่าและการชำระของลูกค้ามีแถวเงินมัดจำแยก และมีหมายเหตุบอกว่าเป็นค่าเช่าเดือนแรก/รอบบิลไหน
- modal สลิปของพนักงานบอกว่าสลิปนั้นจ่ายอะไรบ้าง รายการละเท่าไร

## 3. หน้า "สัญญาเช่าของฉัน" (ผู้เช่า) และ modal สัญญา (พนักงาน/ผู้ดูแล)

ทั้งสองที่ใช้ component เดียวกัน (`CustomerContractBody`) หน้าตาจึงเหมือนกัน

- การ์ดขนาดคงที่ ไม่ยืดตามจำนวนรูป
- **หัว modal (พนักงาน):** ไอคอนคน, ชื่อ, ป้ายเบอร์โทร, ป้ายวันทำสัญญาสีฟ้า, ป้ายสถานะเรียงแนวนอน
- **แถบช่วงสัญญา** (`ContractPeriodTimeline`): `เริ่มสัญญา - - (X เดือน) - -› สิ้นสุด` และ "เดือนที่ x/y · เหลือ X วัน" ถ้าต่อสัญญาแล้วขึ้น "ต่อสัญญาถึง"
- **แถบรอบบิลรายเดือน** (`ContractMonthTrack`): ช่องละ 1 เดือน ผ่านแล้ว/เดือนนี้/ที่เหลือ และช่วงต่อสัญญาเป็นเส้นประ ใช้ทั้งหน้าผู้เช่า modal พนักงาน และหน้าผู้ดูแล
- **รายละเอียดสัญญา:** ระยะทั้งหมด ผ่านไป เหลืออีก, วันที่มีสี (เริ่มเขียว สิ้นสุดส้ม ต่อถึงน้ำเงิน), เงินมัดจำ "฿6,000 (2 เดือน) · ชำระแล้ว" สีตามสถานะ
- **คำเตือน (เฉพาะผู้เช่า):** "ย้ายออกก่อนสัญญาหมด จะไม่ได้รับเงินมัดจำคืน" จนกว่าสัญญาจะจบ

### การ์ด "ยอดตามสัญญารวมทุกเดือน" (`.ccc-bill`)

```
ยอดตามสัญญารวมทุกเดือน                            3 รอบบิล
ค่าเช่าทุกเดือนตลอดสัญญา 23 ต.ค. 69 ถึง 23 ม.ค. 70 [3 เดือน]
23 ต.ค. 69 ถึง 23 พ.ย. 69 [ห้อง 102]                   ฿3,200
23 พ.ย. 69 ถึง 23 ม.ค. 70 [ห้อง 101] ฿3,000 × 2 เดือน    ฿6,000
รวมค่าเช่าตามสัญญา                                      ฿9,200
ชำระแล้ว                                              − ฿3,200
[เงินมัดจำ 2 เดือน · ชำระแล้ว                          ฿6,000]
   หักไป −฿200   คงเหลือ ฿5,800             ดูรายการหัก ›
[ค่าเช่าเดือนนี้ ...                          ดูบิล]
```

- สัญญาที่ย้ายห้อง แยกค่าเช่าตามช่วงที่อยู่ห้องไหน ส่วนต่างย้ายห้องรวมเข้าไปในเดือนที่จ่ายจริง (backend `contractRentBreakdown` → `rent_breakdown`) ยอดรวมเท่ากับ `contract_total`
- ไม่มีบรรทัด "ค่าเช่าที่เหลือ" แล้ว (ลบออก 23 ต.ค.)
- เงินมัดจำ: ตัวเลขใหญ่เป็นยอดที่จ่ายจริง ถ้าถูกหักตอนย้ายห้อง มี dropdown "ดูรายการหัก" (`DepositDeductions`)
- **ค่าเช่าเดือนนี้** (`ThisMonthRent`): ชำระแล้ว (เขียว) / รอชำระ (ส้ม) / เกินกำหนด (แดง) / รอตรวจสลิป (ฟ้า) / ไม่มีรอบบิล (เขียว เด่นกว่ากล่องมัดจำ) แสดงรอบบิล วันครบกำหนด จำนวนเดือนค้าง
- **ดูบิล** (`RentBillModal`): ใบแจ้งค่าเช่าขนาดคงที่ มีรายการ ยอด สถานะ ราคาตามสัญญา และรูปสลิปถ้าจ่ายแล้ว (ถ้าจ่ายที่เคาน์เตอร์บอกว่าไม่มีสลิป)

## 4. หน้า "สัญญาที่เสร็จสมบูรณ์" (พนักงาน / ผู้ดูแล / เจ้าของ)

- ทั้ง 3 บทบาทใช้หน้าเดียวกัน (`StaffCompletedContracts`) มีตัวกรองสถานะ ประเภทสัญญา (ปัจจุบัน/เก่า/รอคืนริบมัดจำ) ช่วงวันที่ ค้นหา และเรียงลำดับ รายการเลื่อนในกรอบ
- **การ์ดสัญญา** (`csc-card`): เลขห้อง ชื่อ เบอร์ ป้ายสถานะ แถบช่วงสัญญา ยอดเงิน 3 ช่อง รูปสัญญา 4 ช่อง
- **สถานะ:** สัญญามีผล, **ย้ายห้องแล้ว** (ใหม่), รอชำระงวดแรก, รอตรวจสลิปงวดแรก, ยังไม่เริ่ม, หมดอายุ, สิ้นสุดการเช่า, **ออกก่อนสัญญา**
- สัญญาที่ย้ายห้อง: กล่องห้องแสดงห้องปัจจุบัน และบรรทัด "ย้ายห้อง X ครั้ง"
- สัญญาเก่า: การ์ดโทนเทา ข้อความ "สัญญาเก่า · มีสัญญาใหม่แล้ว" ใต้เบอร์โทร
- สัญญาที่ออกก่อนกำหนด: การ์ดจางออกแดง
- ป้ายคืน/ริบมัดจำแบบย่อในการ์ด และป้ายเหลือง **"รอบันทึกริบมัดจำ / รอคืนมัดจำ"** ถ้ายังไม่ได้จัดการ
- modal สัญญาขนาด 1240×860 สัญญาเก่าที่มีกล่องแจ้งด้านบนเลื่อนลงได้

## 5. หน้าผู้ดูแล (Admin)

- **modal รายละเอียดลูกค้า:** แสดงเฉพาะสัญญาปัจจุบัน (`loadCustomerContracts({ currentOnly })`) ถ้าลูกค้าถูกระงับยังเห็นสัญญาเดิมพร้อมป้าย "สัญญาเก่า" ที่หัวข้อ ปลดระงับแล้วสัญญาเก่าหายจากส่วนนี้ ประวัติย้ายห้องแสดง 2 ครั้งล่าสุด รูปสัญญาเก่า/ใหม่เป็น dropdown (ปิดไว้) และมีปุ่มดูประวัติย้ายห้องทั้งหมด (modal ค้นหาได้)
- **modal รายละเอียดห้อง:** ป้ายสถานะสัญญา กล่องแจ้งงวดแรก/คืนริบมัดจำ แถบวันที่ แถบรอบบิล และ 4 กล่อง: ค่าเช่า/เดือน, เงินมัดจำ (ยอดที่เหลือจริง), ชำระแล้ว, ยอดตามสัญญา การ์ดผู้เช่าในประวัติห้องรองรับระบบใหม่
- **ตารางลูกค้า:** คอลัมน์สัญญา/มัดจำเหลือ 2 บรรทัด เช่น `฿3,000 · 9 เดือน [ต่อแล้ว]` / `มัดจำ ฿6,000 · ชำระแล้ว`
- ห้องที่มีผู้เช่าแก้ไขหรือลบไม่ได้ (backend ตอบ 409) แก้ยอดเงินมัดจำในฟอร์มลูกค้าไม่ได้

## 6. ต่อสัญญา

- ต่อจากวันสิ้นสุดเดิม ไม่เริ่มนับใหม่ จ่ายรายเดือนเท่านั้น (เอาตัวเลือกจ่ายทบก้อนออก) ไม่เก็บมัดจำเพิ่ม
- ออกก่อนวันสิ้นสุด **ใหม่** ยังโดนริบมัดจำ
- ต้องไม่มียอดค้าง (ค่าเช่าเลยกำหนด ค่าน้ำไฟ มัดจำ) — ปุ่มเปลี่ยนเป็น "ชำระยอดค้าง" และ server ปฏิเสธ
- ฟอร์มลูกค้าและ modal พนักงานมีตาราง "สัญญาตอนนี้ → หลังต่อสัญญา" และข้อความเรื่องมัดจำ

## 7. ย้ายห้อง

- ผู้เช่าต้องจ่ายยอดค้างก่อน (`MOVE_ROOM_OUTSTANDING`) ส่งได้ทีละคำขอ เลือกห้องว่าง เหตุผล และวันที่ภายใน 60 วัน
- **ต้องพักครบ 15 วัน** นับจากวันเริ่มสัญญาหรือวันย้ายห้องครั้งล่าสุด (อันที่ใหม่กว่า) จึงขอย้ายได้ (`MOVE_ROOM_COOLDOWN_DAYS`, `MOVE_ROOM_TOO_EARLY`)
- พนักงานตรวจห้องเดิม แล้วอนุมัติผ่านหน้าสรุป (`transfer-preview`) มีเช็กลิสต์ความพร้อม
- **คิดเงิน:** ห้องใหม่แพงกว่า → ส่วนต่าง × รอบที่จ่ายไปแล้ว หักจากมัดจำคงเหลือก่อน · ราคาเท่าหรือถูกกว่า → ไม่หักไม่เก็บ · รอบถัดไปคิดราคาห้องใหม่ วันสิ้นสุดเดิม
- **มัดจำไม่พอ → ต้องจ่ายก่อนทำสัญญา:** พนักงานกด "ส่งยอดเก็บเงิน" (`POST /requests/:id/transfer-charge`) ระบบสร้าง Payment `room_transfer` บน booking ห้องเดิม ให้ผู้เช่าจ่ายภายใน 3 วัน (`TenantRequest.transfer_charge_payment_id`, `transfer_charge_due_at`, `transfer_charge_periods` ล็อกจำนวนรอบไว้) ระหว่างนี้ยังไม่ย้ายห้อง ห้องปลายทางถูกกันไว้ (`loadHeldTransferRooms` / `roomHeldForTransfer`): ไม่โชว์ในห้องว่างให้ลูกค้าคนอื่นขอย้ายเข้า แต่**หน้าลงทะเบียนยังเลือกได้** (`/api/rooms/available` ส่ง `held_for_transfer` มา หน้าลงทะเบียนเตือนว่าจะยกเลิกคำขอย้ายของผู้เช่าเดิม) ถ้าลงทะเบียนเข้าไป คำขอย้ายห้องและยอดส่วนต่างที่ยังไม่ส่งสลิปถูกยกเลิกทันที ผังห้องของ staff ขึ้นป้าย "ว่าง · มีผู้เช่ารอย้ายเข้า" อนุมัติได้เมื่อสลิปตรวจผ่าน (Payment = `paid`) แล้วใช้ Payment เดิมเป็น `RoomTransfer.charge_payment_id`
- **ห้องปลายทางมีคนเข้าพักแล้ว → ยกเลิกคำขอย้ายห้องอัตโนมัติ** (`cancelTransfersIntoBookedRooms`) พร้อมยกเลิกยอดส่วนต่างที่ยังไม่ส่งสลิป เรียกตอนลงทะเบียนผู้เช่าใหม่, ตอนอนุมัติย้ายห้องของอีกคนเข้าห้องเดียวกัน และในรอบตรวจ `expireRoomTransferCharges` (กันกรณีห้องถูกจองจากทางอื่น)
- เลย 3 วันโดยไม่มีสลิป → `expireRoomTransferCharges` ยกเลิกคำขอ (`cancelled` + `reject_reason`) และยกเลิก Payment (`cancelled`) ถ้าส่งสลิปทันก่อนกำหนดจะรอการตรวจ ถ้าสลิปถูกปฏิเสธหลังเลยกำหนดจะยกเลิกในรอบถัดไป · ฟังก์ชันนี้รันตอนเรียก API (รายการคำขอ staff, preview, approve, dashboard ลูกค้า, ส่งคำขอ, ชำระเงิน) ไม่มี cron
- **ต้องแนบรูปสัญญาใหม่อย่างน้อย 5 รูป** ก่อนกดยืนยัน รูปใหม่เป็นรูปหลัก รูปเก่าเก็บเป็นประวัติผูกกับการย้ายครั้งนั้น
- บันทึกใน `RoomTransfer` (ห้อง/ราคาเดิม-ใหม่ ส่วนต่าง มัดจำที่หัก ยอดเก็บเพิ่ม) กันอนุมัติซ้ำ
- โค้ดย้ายห้องรวมอยู่ใน `router/rentalContracts.js` (ลบ `roomTransfer.js`) เทสต์ `tests/roomTransfer.test.js`
- หน้าสัญญาทุกฝั่งแสดงประวัติการย้าย (ครั้งที่ วันที่ ราคา มัดจำที่หัก ยอดเก็บเพิ่ม) และ modal ประวัติทั้งหมดที่ค้นหาได้

## 8. แจ้งย้ายออก

- ผู้เช่าเลือกวันย้ายออก (ภายใน 60 วัน) modal บอกรายละเอียดสัญญาและผลกระทบตามวันที่เลือก เช่น "ย้ายออกก่อนสิ้นสุดสัญญา 84 วัน จะไม่ได้รับเงินมัดจำ ฿6,000 คืน"
- มียอดค้าง → ปุ่มเปลี่ยนเป็น "ชำระยอดค้าง"
- พนักงานต้องตรวจห้องก่อนอนุมัติ (`MOVEOUT_OUTSTANDING` ถ้ายังค้าง) หน้าอนุมัติแสดงวันที่ย้าย ก่อนครบกี่วัน ผลตรวจห้อง ยอดค้าง และผลต่อมัดจำ
- ปฏิเสธต้องพิมพ์เหตุผล ผู้เช่าเห็นเหตุผลนั้น
- อนุมัติแล้ว: ห้องว่าง สัญญาปิด (`Booking.ended_at`) บัญชีไม่ถูกระงับแต่ไม่มีห้อง

## 9. ระงับบัญชี สัญญาเก่า และทำสัญญาใหม่

- ระงับ → ปิดสัญญา (`ended_at`) ล้างห้อง ยกเลิกคำขอค้าง พัสดุที่ยังไม่รับเป็น "ยกเลิก" และตั้ง `history_reset_at` ให้ฝั่งผู้เช่าเริ่มใหม่ (ประวัติยังอยู่ในหน้าพนักงาน/ผู้ดูแล)
- เก็บวันที่ระงับใน `Customer.suspended_at` และนับเป็นวันย้ายออก ผู้เช่าที่ระงับไปก่อนหน้า ดึงวันที่จริงจาก `AuditLog` มาใส่ให้
- บัญชีที่ไม่มีห้อง เข้าสู่ระบบไม่ได้ ("ไม่พบบัญชีผู้ใช้นี้")
- พัสดุของผู้เช่าคนก่อนมีป้าย "ผู้เช่าคนก่อน" และขั้นตอนขึ้นว่า "ผู้เช่าย้ายออก"
- สัญญาเก่าแสดงป้ายสีเทา "สัญญาเก่า" และป้ายฟ้า "มีสัญญาใหม่แล้ว"

## 10. คืน / ริบเงินมัดจำ

### สถานะที่ระบบคำนวณ

| สถานะสัญญา | `deposit_refund` |
|---|---|
| ออกก่อนครบสัญญา (`ended_early`) | `forfeit` (ริบ) |
| อยู่ครบ (`ended`) / หมดอายุ (`expired`) | `refund` (คืน) |

`can_settle_deposit` = สัญญาสิ้นสุด + มีมัดจำคงเหลือ + ยังไม่เคยบันทึก

### การบันทึก

- ในหน้าสัญญามีการ์ดเหลือง "ยังไม่ได้จัดการเงินมัดจำ" + ปุ่มเปิด `DepositSettlementModal`
- ระบบเลือกคืน/ริบให้อัตโนมัติ พนักงานเลือกเองไม่ได้ backend ตรวจซ้ำ (ไม่ตรงเงื่อนไขตอบ 409)
- modal แสดง: สรุปยอด, **เงื่อนไขสัญญา** (`DepositContractTerms`: ระยะสัญญา มัดจำ วันย้ายออก ก่อนครบกี่วัน ผลตรวจห้อง กฎ 2 ข้อพร้อมป้าย "ผิดเงื่อนไขข้อนี้"), ช่องหักค่าเสียหาย (กรณีคืน), เหตุผล, สรุปยอด
- บันทึกลง `Booking.deposit_*` และเขียน log
- หลังบันทึก กล่องผล 2 บรรทัด: หัวข้อ + ลิงก์ดูบันทึก / เหตุผล · ชื่อพนักงาน · วันที่

### บันทึกการจัดการเงินมัดจำ (log)

- ตาราง `DepositSettlementLog` (staff schema) เก็บ ห้อง ผู้เช่า คืน/ริบ ยอดเงิน เหตุผล สถานะสัญญา `left_at` `contract_end_date` `left_reason` ผู้บันทึก เวลา เติมข้อมูลย้อนหลังให้แล้ว
- เปิดได้จากลิงก์ในแต่ละสัญญา หรือปุ่มที่หัวหน้า "สัญญาที่เสร็จสมบูรณ์" (มีตัวเลขแดงรอจัดการ)
- แบบทุกสัญญา: หัว modal สรุปยอดคืน/ริบ, แท็บ **ประวัติ** (กล่องรอจัดการ 3 รายการ + "ดูทั้งหมด") และ **รอจัดการ** (ทุกรายการ), ค้นหาได้
- แถวรอจัดการกางดูเงื่อนไขที่ผิดได้ และกดบันทึกริบ/คืนได้จากในนี้
- รายการริบมี dropdown "ผิดสัญญา: ย้ายออกก่อนครบสัญญา [ก่อนครบ X วัน]" แสดงวันออก (ป้ายสีตามเหตุ) วันสิ้นสุด และข้อที่ผิด
- dropdown ทั้งหมดมี animation เปิด/ปิด 0.08s และ Esc ปิดเฉพาะ modal บนสุด

## 11. เงื่อนไขสัญญาเช่าในหน้ากฎระเบียบ

- เจ้าของ/ผู้ดูแลแก้ "เงื่อนไขสัญญาเช่า" ได้ในหน้าจัดการกฎระเบียบ (`DormConfig.contract_rules`) แบ่งหัวข้อ/ข้อ ปุ่ม "เพิ่มข้อ" ใส่ใต้หัวข้อที่เลือกอยู่
- ปุ่ม "เติมอัตโนมัติจากระบบ" สร้างเงื่อนไขจากค่าที่ backend ใช้จริง (ทำงานเฉพาะตอนกด)
- ถ้าไม่ได้กรอก ส่วนนี้ไม่แสดงให้ผู้เช่าเห็น

## 12. สิทธิ์การเข้าถึงสัญญา (กันที่ backend)

| ผู้ใช้ | ข้อมูลสัญญา | รูปสัญญา |
|---|---|---|
| ลูกค้า | เฉพาะของตัวเอง (id จาก token) | เฉพาะของตัวเอง |
| ลูกค้าคนอื่น / ไม่ล็อกอิน | ไม่เห็น (404 / 401) | ไม่เห็น |
| พนักงาน / ผู้ดูแล / เจ้าของ | ทุกสัญญา | ทุกรูป |

ลิงก์และ modal บันทึกมัดจำ แสดงเฉพาะฝั่งพนักงาน
