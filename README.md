# projectcsi400 — ระบบจัดการหอพัก

เว็บแอปสำหรับบริหารหอพัก ครอบคลุมงานของ 4 บทบาทในที่เดียว

- **ผู้เช่า** — ดูสัญญาเช่า จ่ายค่าเช่า/ค่าน้ำไฟผ่าน QR แจ้งซ่อม ขอต่อสัญญา ย้ายห้อง หรือย้ายออก และดูพัสดุ
- **พนักงาน (Staff)** — ลงทะเบียนผู้เช่าและสัญญา ตรวจสลิป ออกบิลค่าน้ำไฟ ตรวจห้อง จัดการคำขอ พัสดุ และคืน/ริบเงินมัดจำ
- **ผู้ดูแล (Admin)** — จัดการห้อง ผู้เช่า พนักงาน ประกาศ และดูประวัติการทำงานทั้งหมด
- **เจ้าของ (Owner)** — ดูรายรับ รายจ่าย อัตราการเข้าพัก และตั้งค่าข้อมูลหอพัก

## เทคโนโลยี

- **Frontend:** React + Vite
- **Backend:** Express แบ่งเป็น microservice 9 ตัว อยู่หลัง API Gateway
- **Database:** MySQL แยกฐานข้อมูลตาม service
- **Infra:** Docker Compose

## เริ่มต้นใช้งาน

```bash
docker compose up -d --build   # backend + database
npm run dev                    # frontend
```
